# Yu Ya Ting - Personal Space & Live Dashboard

A modern personal website featuring live precision timekeeping, responsive bento-grid layout, dynamic theme switching, and client-side profile persistence.

## Features

- **Live Chrono Clock**: Tabular digital clock with 12H/24H format toggling and time-of-day greetings.
- **Dynamic Themes**: Instant switching between Aurora, Obsidian, Cyber, and Sunset color palettes.
- **World Clocks**: Real-time synchronized time zones (New York, London, Tokyo, Sydney).
- **Calendar & Year Insights**: Day of year, week number, and day/year progress calculation.
- **In-Place Customization**: Instant profile editing with LocalStorage persistence.

## Technologies

- HTML5 (Semantic Structure)
- Vanilla CSS3 (Custom Properties & Glassmorphism)
- Vanilla JavaScript (ES6+)
